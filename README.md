# Single and Multi-Object Recognition with CNN Classification and YOLOv8 Detection

A two-stage recognition system for 73 real-world objects. Given a photo of one object, it returns the object's ID. Given a photo with many objects, it returns the ID **and location** of each one.

| Stage | Model | Test Result |
|---|---|---|
| Single-object classification | EfficientNetB0 (transfer learning) | **94.17% accuracy**, macro F1 0.941 |
| Multi-object detection | YOLOv8s (COCO-pretrained, fine-tuned) | **mAP50 0.806**, mAP50-95 0.765, 12.4 ms/image |

**Highlights**
- Cleaned 7,345 raw photos into 7,315 images (corrupt-file checks, MD5-hash deduplication) across 73 classes
- Compared four classifiers and showed transfer learning beats training from scratch by 16.5 to 19.7 accuracy points
- Built a **3,749-image multi-object dataset** from single-object photos using grid compositing with automatic box-label transformation, split *before* compositing to prevent test leakage
- Auto-labeled bounding boxes with **Grounding DINO** (text-prompted, zero-shot) instead of manual annotation
- Served both tasks through **one detector** with two inference modes, tuned per task

## 1. Dataset

About 100 photos were taken of each of 73 objects under varied lighting, angles, and backgrounds, plus photos of empty backgrounds. All images are 224×224 RGB.

| Property | Value |
|---|---|
| Raw files | 7,345 |
| After cleaning | 7,315 (2 non-JPEG files and 28 exact duplicates removed) |
| Classes | 73 (94 to 113 images each, mean 100) |
| Split | Stratified 70/15/15, seed 42 (5,120 / 1,097 / 1,098) |

### Multi-object grids
The dataset only has single-object photos, so multi-object images were generated by pasting shuffled single images into grids (2×2, 3×3, 4×4, 5×4, 5×5; canvases from 448 to 1120 px). Each tile's box is shifted by the tile offset and rescaled to the full canvas, and every grid gets one label file with all its boxes.

**Leakage prevention:** photos were split into train/val/test *first*, and grids are only built from photos within the same split, so no test photo ever appears in a training grid.

| Layout | Train | Val | Test |
|---|---|---|---|
| 2×2 | 1,280 | 274 | 274 |
| 3×3 | 568 | 121 | 122 |
| 4×4 | 320 | 68 | 68 |
| 5×4 | 256 | 54 | 54 |
| 5×5 | 204 | 43 | 43 |
| **Total** | **2,628** | **560** | **561** |

## 2. Single-Object Classification

### Models
- **Baseline CNN** from scratch: 4 conv blocks (32/64/128/256 filters, BatchNorm, max pooling), global average pooling, dropout 0.4. 409K parameters.
- **MobileNetV2, ResNet50, EfficientNetB0**: ImageNet-pretrained backbones with a new dropout (0.3) + 73-class softmax head.

### Training
- Shared augmentation: random flip, rotation, zoom, and contrast
- Adam optimizer, early stopping (patience 5), learning-rate reduction on plateau
- Pretrained models trained in **two stages**: frozen backbone (lr 1e-3), then the last 30 layers unfrozen with BatchNorm kept frozen (lr 1e-5)

### Results (1,098 test images)

| Model | Accuracy | Macro F1 | Params |
|---|---|---|---|
| Baseline CNN | 0.7450 | 0.7465 | 0.41M |
| MobileNetV2 | 0.9098 | 0.9102 | 2.35M |
| ResNet50 | 0.9381 | 0.9392 | 23.74M |
| **EfficientNetB0** | **0.9417** | **0.9413** | **4.14M** |

**EfficientNetB0 was selected:** it has the best accuracy and F1, and it is about 5.7× smaller than ResNet50, the only model with comparable accuracy. 20 of 73 classes are classified perfectly and 57 reach F1 above 0.90.

## 3. Multi-Object Detection

### Setup
YOLOv8s was fine-tuned from COCO weights by replacing the 80-class head with a 73-class head. 349 of 355 weight tensors were reused from the pretrained checkpoint.

| Setting | Value |
|---|---|
| Input size | 1024 (keeps 5×5 grid tiles about 200 px wide, vs. about 128 px at 640) |
| Batch size | 5 |
| Optimizer | AdamW, lr 0.00013 |
| Epochs | 71 run, best at epoch 51 (early stopping, patience 20) |
| Training time | 2.6 hours on one T4 GPU |
| Augmentation | Mosaic, flips, shift/scale, HSV jitter, blur, grayscale |

### Results

| Set | Precision | Recall | mAP50 | mAP50-95 |
|---|---|---|---|---|
| Validation | 0.897 | 0.777 | 0.824 | 0.779 |
| Test (561 grids, 7,058 boxes) | 0.866 | 0.783 | 0.806 | 0.765 |

Validation and test scores are within 0.02, so the model is not overfit to the validation set. The small gap between mAP50 and mAP50-95 (0.04) shows the boxes are tight once an object is found.

## 4. Recognition System

One trained detector serves both tasks with different inference settings:

| Mode | Input size | Confidence threshold | Output |
|---|---|---|---|
| Single object | 512 | 0.15 | Top-3 IDs with names and scores, best box drawn |
| Multi-object | 1024 | 0.35 | Every detection with ID, name, confidence, and box |

**Input size study** on 300 held-out single-object photos:

| Input size | Top-1 accuracy | Detection rate |
|---|---|---|
| 320 | 0.890 | 0.917 |
| **448** | **0.893** | 0.930 |
| 512 | 0.887 | 0.920 |
| 640 | 0.883 | 0.947 |
| 1024 | 0.813 | 0.903 |

## 5. Error Analysis

- **Missed objects, not confused objects.** The confusion matrix is strongly diagonal, and most errors fall in the background row (objects not detected). In 53 of 73 classes, precision is higher than recall: when the model fires, it is usually right.
- **Visually similar classes.** OBJ059 and OBJ061 are confused with each other in both classification and detection. OBJ034 has the lowest classification recall (0.67).
- **Weakest detection classes.** About a dozen classes fall below 0.60 mAP50-95, with OBJ068 lowest at 0.29, while 16 classes reach 0.90 or higher.
- **Duplicate boxes.** Some objects get a second low-confidence box, traced back to source photos that were auto-labeled with more than one box.
- **Overfitting after epoch 15.** Validation mAP50 plateaus near 0.82 while training losses keep falling, so later epochs mostly fit the training grids better.

## 6. Limitations

- Grid images have no overlap, clean tile borders, and roughly one object scale, so results describe grid-style images rather than cluttered real scenes. Tile borders are also an artificial cue.
- Each class is one specific physical item, so the system recognizes those exact objects rather than object categories.
- With about 15 test images per class, one mistake moves a class's recall by about 7 points.
- Each photo appears in up to five grids, and training used a single seed, so run-to-run variation isn't measured.

## 7. Next Steps

- Clean duplicate auto-generated labels and measure label quality
- Generate grids with varied object sizes, positions, and overlaps to look more like natural scenes
- Extend to **instance segmentation** (e.g., YOLOv8-seg, or SAM prompted with Grounding DINO boxes)
- Run multiple seeds to measure variance
